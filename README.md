# The LifeTime Fishing Fund

A mission-driven company dedicated to making fishing accessible and supporting conservation through transparent community funding.

This repository serves as the public ledger, mission hub, and documentation center for all fund activity.

## Mission
We make fishing accessible. We fund conservation. We operate as a for-profit mission company with full transparency.
